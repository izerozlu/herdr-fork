Forks run in their own Herdr tab. To fork this session (start an agent that already has this conversation as context), run `herdr-fork [-C <subdir>] <name> "<task>"` in Bash. Do not use the Agent tool with subagent_type "fork"; the herdr-fork hook blocks it. A fork shares this session's checkout and branch unless you give it a git worktree with -C, so give parallel forks separate files. Its report goes to `/tmp/herd/<name>.md`; `herdr-fork list` shows the agents in this workspace and `herdr-fork close <name>` closes a fork's tab.
